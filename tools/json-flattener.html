JSON Flattener

Turn nested JSON into flat key-value pairs — or rebuild nested JSON from flat keys.

Runs entirely in your browser — nothing is uploaded. Dot notation: user.name, user.tags[0]. Bracket notation: user[name], user[tags][0]. Underscore notation: user_name (note: keys that already contain underscores cannot be round-tripped reliably with underscore mode). Invalid JSON shows an error instead of partial output.
