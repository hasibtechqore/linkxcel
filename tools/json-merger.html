JSON Merger

Merge two JSON documents into one, choosing what happens when the same key holds different values.

Runs entirely in your browser — nothing is uploaded. Nested objects are merged deeply (keys combine at every level). Second wins: the second document's value replaces the first. First wins: the first value is kept. Combine into array: both values are kept as [first, second]. Merging an object with an array, or two different primitive types, follows the same strategy.
